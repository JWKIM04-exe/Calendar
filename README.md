# 대체복무 공유 캘린더

대체복무요원 여러 명이 함께 쓰는 주간 계획표입니다.

- 각자 **비밀번호**를 정해 등록하고 로그인합니다. 본인 일정과 정보는 본인만 고칠 수 있습니다 (서버에서 비밀번호로 확인)
- 등록한 정보(이름, 복무기관, 생활관, 복무 기간)로 D-day와 진행률이 보입니다
- **빠른 추가**: `12일 오전9시 다이소가기, 15일 오후7시 오징어먹기 빨강`처럼 글로 적으면 날짜·시간·색을 알아서 넣습니다
- 일정마다 **색**을 고를 수 있고, 등록한 일정은 눌러서 고칠 수 있습니다
- 오른쪽 위 달력 버튼으로 **한 달 보기**를 엽니다 (전체 / 나만 / 다른 사람 모두 / 한 사람)
- 요일마다 **거주 형태**(시설 합숙 / 외출 / 외박 / 휴가 / 출퇴근)를 고를 수 있습니다
- 일정(근무, 교육·훈련, 개인, 외출·외박, 공지)을 추가하면 **같은 그룹 사람 모두에게 실시간으로** 보입니다
- 사람별 색으로 구분되고, 위쪽 이름 칩을 눌러 특정 사람만 볼 수 있습니다
- 주마다 목표와 메모를 적고, 다른 사람의 목표도 볼 수 있습니다
- **그룹 코드**(`?g=코드`)로 여러 팀이 같은 사이트를 따로따로 쓸 수 있습니다

기술: HTML, 순수 JavaScript, Supabase. 빌드 과정이 없습니다. 헬스기록 앱과 같은 Supabase 프로젝트를 씁니다.

사이트 주소: https://jwkim04-exe.github.io/Calendar/

## 처음 한 번만: Supabase 테이블 만들기

1. https://supabase.com/dashboard 에서 헬스기록 프로젝트를 엽니다
2. 왼쪽 메뉴에서 **SQL Editor**를 누르고 **New query**를 엽니다
3. 이 저장소의 `supabase.sql` 내용을 전부 붙여넣고 **Run**을 누릅니다

테이블 이름이 `cal_`로 시작해서 헬스기록의 테이블과 섞이지 않습니다. 테이블이 없거나 연결에 실패하면 사이트 위쪽에 안내가 뜨고, 그동안은 로컬 모드(이 브라우저에만 저장)로 동작합니다.

다른 사람이 올린 일정은 10초마다, 그리고 창으로 돌아올 때 자동으로 새로고침됩니다.

## 3. 함께 쓰기

- 사이트의 **초대 링크 복사** 버튼을 눌러 동료에게 보냅니다
- 팀별로 따로 쓰려면 주소 뒤에 `?g=팀이름`을 붙이세요. 예: `.../?g=seoul-team-a`
- 링크를 아는 사람은 누구나 그 그룹의 일정을 **볼 수** 있고, 새로 등록할 수도 있습니다. 하지만 다른 사람의 일정은 그 사람 비밀번호 없이는 고칠 수 없습니다
- 비밀번호는 서버에 암호화(bcrypt)되어 저장되고, 화면이나 API로는 보이지 않습니다
- 비밀번호를 아직 정하지 않은 기존 사람은 처음 로그인할 때 입력한 비밀번호가 그 사람의 비밀번호가 됩니다
- 비밀번호를 잊었다면 Supabase의 Table Editor에서 `cal_members` 표의 해당 사람 `pw_hash` 칸을 비우면 됩니다. 그러면 다음 로그인 때 새로 정할 수 있습니다

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 화면과 스타일 |
| `app.js` | 동작 (Supabase와 로컬 저장소) |
| `quick.js` | 빠른 추가 글 읽기 (날짜·시간·색) |
| `bump.sh` | 업데이트할 때 버전 번호 갱신 (휴대폰 캐시 방지) |
| `config.js` | Supabase 주소, 공개 키, 기본 그룹 코드 |
| `supabase.sql` | 테이블과 보안 규칙 (SQL Editor에서 한 번 실행) |

## 데이터 구조 (Supabase 테이블)

```
cal_members  그룹, id, 이름, 기관, 생활관, 복무 시작일과 종료일
cal_events   그룹, 날짜, 시간, 내용, 분류, 작성자, 완료 여부
cal_stays    그룹, 멤버, 날짜, 거주 형태
cal_memos    그룹, 멤버, 주 시작일, 목표, 메모
cal_sessions 로그인 토큰 (암호화, 바깥에서 접근 불가)
```

## 앞으로 붙일 만한 기능

- 월간 달력 보기
- 외박·휴가 남은 일수 계산
- 관리자 권한 (공지는 관리자만 쓰기)
- 비밀번호나 구글 로그인
